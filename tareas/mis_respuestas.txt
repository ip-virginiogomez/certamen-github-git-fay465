----------------------------------------------------------------
PREGUNTA 1 (5 pts)
¿Cuál es la diferencia entre "git add" y "git commit"?

Tu respuesta:
"git add" prepara archivos para el commit, mientras que git commit es guardar los cambios localmente.

----------------------------------------------------------------
PREGUNTA 2 (5 pts)
¿Qué hace el comando "git pull"? ¿Cuándo debes usarlo?

Tu respuesta:
Es descargar los cambios del repositorio, se usa cuando quieres "actualizar" el repositorio local con los cambios más recientes.

----------------------------------------------------------------
PREGUNTA 3 (5 pts)
¿Qué diferencia hay entre un repositorio local y uno remoto?

Tu respuesta:
El repositorio local es, como lo dice el nombre, local (se almacena dentro del ordenador), mientras que el remoto es un respaldo o archivo final subido en la nube (github)  

----------------------------------------------------------------
PREGUNTA 4 (5 pts)
Escribe la secuencia completa de comandos para subir un nuevo
archivo llamado "datos.csv" a GitHub (desde git add hasta push):

Tu respuesta:
git init
git add datos.csv
git commit -m "primer commit"
git push origin main
